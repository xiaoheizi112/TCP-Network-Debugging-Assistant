# TCP Network Debugging Assistant

## 项目背景

TCP Network Debugging Assistant（TCP网络调试助手）是一个基于Qt框架开发的网络调试工具，旨在为开发者和网络工程师提供便捷的TCP网络通信测试和调试功能。该项目包含客户端和服务端两个独立的应用程序，支持多客户端连接、实时数据传输和网络通信状态监控。

## 技术栈

- **开发框架**: Qt 5/6
- **编程语言**: C++17
- **核心模块**: Qt Network (QTcpSocket, QTcpServer)
- **UI框架**: Qt Widgets
- **构建系统**: qmake (.pro文件)

## 已实现功能

### TCP客户端 (TcpClient)

- **连接管理**
  - 支持自定义服务器IP地址和端口号连接
  - 自动连接超时检测（5秒超时机制）
  - 实时连接状态显示和错误处理
  - 优雅的连接断开处理

- **数据通信**
  - 实时数据发送和接收
  - 彩色文本显示（发送数据为蓝色，接收数据为黑色）
  - 支持多行文本发送
  - 自动滚动到最新消息

- **用户界面**
  - 直观的图形用户界面
  - 连接参数配置区域
  - 数据收发显示区域
  - 连接/断开/发送按钮控制

### TCP服务端 (TcpServer)

- **服务器管理**
  - 支持多网卡IP地址选择
  - 自定义端口号监听
  - 端口占用检测和错误提示
  - 服务器启动/停止控制

- **多客户端支持**
  - 同时支持多个客户端连接
  - 实时客户端连接状态监控
  - 客户端连接/断开事件通知
  - 动态客户端列表管理

- **数据通信**
  - 支持向指定客户端发送数据
  - 支持广播消息到所有客户端
  - 实时显示各客户端发送的数据
  - 客户端标识和数据来源追踪

- **高级功能**
  - 自定义ComboBox组件，支持点击刷新客户端列表
  - 智能按钮状态管理
  - 网络接口自动检测和IP地址枚举

## 项目目标

1. **简化网络调试流程**: 提供直观易用的图形界面，降低TCP网络调试的技术门槛
2. **提高开发效率**: 快速验证网络通信功能，缩短开发和测试周期
3. **支持教学演示**: 适合网络编程教学和TCP协议原理演示
4. **实用工具定位**: 成为开发者工具箱中的实用网络调试助手

## 快速开始

### 编译要求
- Qt 5.12+ 或 Qt 6.x
- C++17 支持的编译器
- qmake 构建工具

### 编译步骤
```bash
# 编译服务端
cd TcpServer
qmake TcpServer.pro
make

# 编译客户端
cd ../TcpClient
qmake TcpClient.pro
make
```

### 使用说明
1. 先启动服务端，配置IP地址和端口号，点击"开始监听"
2. 启动客户端，输入服务端IP地址和端口号，点击"连接"
3. 连接成功后即可进行双向数据通信测试
